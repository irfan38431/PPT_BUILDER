# NEW FEATURE: Advanced Multi-Level Table Agent

**Feature ID:** `FEAT-TABLE-AGENT-V2`
**Priority:** HIGH
**Scope:** New agent + refactor existing table rendering pipeline
**Architecture Reference:** `ARCHITECTURE.md`

---

## 1. Problem Statement

### Current State
The existing pipeline produces **flat, single-class tables** — each table has a single row of column headers with one dimension of data (e.g., "Asset Category | Unit Volume | Strategic Status"). These are generated by `SlideContentAgent` → `TableGenerator` / `RichTableGenerator` and rendered via `InteractivePPTGenerator`.

### Desired State
Tables must support **multi-level grouped headers** with:
- **Super-headers** spanning multiple sub-columns (e.g., "Corporate" spanning "Mar-25 | Jul-25 | Abs Growth | Rel. Growth | Aug-25 | Abs Growth | Rel. Growth")
- **Sub-headers** nested under super-headers (e.g., under "Abs Growth": "Mar-25 to July-25"; under "Rel Growth": "MoM (July to Aug)")
- **Conditional cell formatting** with heatmap coloring (green-to-red gradient based on value magnitude/direction)
- **Row highlighting** for special rows (Grand Total, top performers)
- **Dynamic structure** — the header hierarchy varies per table and is decided by an AI agent analyzing the source data

### Visual References
See the attached PPT `Kotak_Comp__Analysis_-_FY26___Real___1_.pptx` for target output:
- **Slide 5** ("Category Wise Break-Up"): 3-level header — "Months" (super) → "Mar-25 | Jul-25 | Aug-25" (sub), "Abs Growth" (super) → "Mar-25 to July-25 | MoM (July to Aug)" (sub), "Rel Growth" (super) → same sub-structure. Full heatmap conditional formatting on growth columns.
- **Slide 6** ("Equity Deep Dive"): 3 separate tables (Corporate / Retail / HNI) each with grouped "Abs Growth / Rel. Growth" super-headers and heatmap cells.
- **Slide 9** ("Debt Deep Dive – Corporate"): "Corporate" as a top-level super-header spanning all data columns, with sub-headers for periods and growth metrics.

## 2. Architecture Changes

### 2.1 New Agent: `TableStructureAgent`

**Location:** `ppt_builder/agents/table_structure_agent.py`

**Role:** Receives raw data (from Excel/DataFrame) + slide context, and produces a **detailed JSON schema** describing the full table structure including multi-level headers, data mapping, formatting rules, and conditional formatting specs.

**Inputs:**
1. `raw_data: pd.DataFrame` — The source data (from Excel file, DuckDB query, or pandas pipeline)
2. `slide_context: SlideContent` — The slide plan including title, narrative, layout intent
3. `theme: PresentationTheme` — Current theme for color derivation
4. `analysis_hint: str` — Natural language hint from the upstream agent about what the table should show (e.g., "Show category-wise AAUM with period comparison and growth metrics, grouped by Months / Abs Growth / Rel Growth")

**Output:** `TableStructureSchema` (new Pydantic model — see Section 3)

**Agent Behavior:**
1. **Analyze** the DataFrame columns, dtypes, value ranges, and row count
2. **Decide** the header hierarchy — which columns are super-headers, which are sub-headers, how many levels deep
3. **Map** each data column to its position in the hierarchy
4. **Define** conditional formatting rules per column (heatmap ranges, thresholds, number formats)
5. **Identify** special rows (totals, subtotals) and their styling
6. **Output** a complete JSON structure that a renderer can consume without any further AI calls

**LLM Prompt Strategy:**
- Use `LLMProvider.generate_structured()` with a Pydantic response schema
- System prompt should include examples of the target table structures (from the reference PPT)
- Input prompt should include: DataFrame `.describe()`, `.dtypes`, `.head(5)`, column names, and the analysis hint
- The agent should be able to handle 1-level (flat), 2-level, and 3-level header hierarchies

### 2.2 New Model: `TableStructureSchema`

**Location:** `ppt_builder/models.py` (extend existing models)

```python
from pydantic import BaseModel, Field
from typing import Optional
from enum import Enum

class HeaderLevel(str, Enum):
    SUPER = "super"      # Top-level group header (e.g., "Corporate", "Months")
    SUB = "sub"          # Second-level header (e.g., "Abs Growth", "Rel Growth")
    LEAF = "leaf"        # Bottom-level actual column header (e.g., "Mar-25", "Jul-25")

class ConditionalFormatType(str, Enum):
    HEATMAP_DIVERGING = "heatmap_diverging"    # Green(+) to Red(-) centered at 0
    HEATMAP_SEQUENTIAL = "heatmap_sequential"  # Light to Dark based on magnitude
    THRESHOLD = "threshold"                     # Fixed color thresholds
    NONE = "none"

class NumberFormat(str, Enum):
    INTEGER = "integer"           # 1,234
    DECIMAL_1 = "decimal_1"      # 1,234.5
    DECIMAL_2 = "decimal_2"      # 1,234.56
    PERCENTAGE = "percentage"     # 12.34%
    PERCENTAGE_INT = "percentage_int"  # 12%
    CURRENCY_CR = "currency_cr"  # ₹1,234 Cr.
    RAW = "raw"                  # As-is

class ColumnSpec(BaseModel):
    """Specification for a single data column (leaf-level)."""
    id: str = Field(description="Unique column identifier, e.g., 'mar_25', 'abs_growth_mar_jul'")
    display_name: str = Field(description="Display text for this column header, e.g., 'Mar-25'")
    source_column: Optional[str] = Field(default=None, description="Column name in the source DataFrame to pull data from. None for computed columns.")
    computation: Optional[str] = Field(default=None, description="Formula for computed columns, e.g., 'jul_25 - mar_25' or 'abs_growth / mar_25'")
    number_format: NumberFormat = Field(default=NumberFormat.INTEGER)
    conditional_format: ConditionalFormatType = Field(default=ConditionalFormatType.NONE)
    width_weight: float = Field(default=1.0, description="Relative width weight for this column")
    text_alignment: str = Field(default="center", description="'left', 'center', 'right'")

class HeaderGroup(BaseModel):
    """A group header that spans multiple sub-headers or leaf columns."""
    id: str
    display_name: str
    level: HeaderLevel
    children: list["HeaderGroup | ColumnSpec"] = Field(description="Child headers or leaf columns under this group")
    background_color: Optional[str] = Field(default=None, description="Override background color hex, e.g., '#8B0000'. None = use theme.")
    text_color: Optional[str] = Field(default=None, description="Override text color hex. None = use theme.")

class RowStyleRule(BaseModel):
    """Conditional styling for specific rows."""
    match_type: str = Field(description="'total', 'subtotal', 'first_n', 'last_n', 'value_match'")
    match_value: Optional[str] = Field(default=None, description="For value_match: the cell value to match in the row label column")
    match_column: Optional[str] = Field(default=None, description="Column to check for value_match")
    bold: bool = False
    background_color: Optional[str] = None
    text_color: Optional[str] = None
    font_size_delta: int = Field(default=0, description="Font size adjustment in pt, e.g., +2 for larger")
    top_border: bool = False
    bottom_border: bool = False

class HeatmapConfig(BaseModel):
    """Configuration for heatmap conditional formatting."""
    min_color: str = Field(default="#FF6B6B", description="Color for minimum/most negative values")
    mid_color: str = Field(default="#FFFFCC", description="Color for zero/middle values")
    max_color: str = Field(default="#4CAF50", description="Color for maximum/most positive values")
    min_value: Optional[float] = Field(default=None, description="Override min boundary. None = auto from data.")
    max_value: Optional[float] = Field(default=None, description="Override max boundary. None = auto from data.")
    center_value: float = Field(default=0.0, description="Center point for diverging heatmaps")

class TableStructureSchema(BaseModel):
    """Complete table structure definition produced by TableStructureAgent."""
    table_id: str = Field(description="Unique identifier for this table")
    title: Optional[str] = Field(default=None, description="Optional table title/caption")
    
    # Header hierarchy — the root level contains super-headers or direct leaf columns
    header_tree: list[HeaderGroup | ColumnSpec] = Field(
        description="Root-level header structure. Can be a mix of HeaderGroup (for multi-level) and ColumnSpec (for flat columns)."
    )
    
    # Row label column
    row_label_column: str = Field(description="Source DataFrame column name used as row labels (leftmost column)")
    row_label_display_name: str = Field(default="", description="Display name for the row label header")
    
    # Data rows configuration
    sort_by: Optional[str] = Field(default=None, description="Column ID to sort rows by. None = preserve source order.")
    sort_descending: bool = True
    max_rows: Optional[int] = Field(default=None, description="Limit number of data rows. None = show all.")
    
    # Styling
    row_styles: list[RowStyleRule] = Field(default_factory=list)
    heatmap_config: HeatmapConfig = Field(default_factory=HeatmapConfig)
    alternate_row_shading: bool = Field(default=True)
    header_height_pts: int = Field(default=36, description="Height of each header row in points")
    data_row_height_pts: int = Field(default=28, description="Height of each data row in points")
    font_size_header: int = Field(default=11)
    font_size_data: int = Field(default=10)
    
    # Layout hints for the PPTX renderer
    table_width_inches: Optional[float] = Field(default=None, description="Override table width. None = auto-fit slide.")
    table_left_inches: Optional[float] = Field(default=None)
    table_top_inches: Optional[float] = Field(default=None)
```

### 2.3 New Renderer: `AdvancedTableRenderer`

**Location:** `ppt_builder/generators/advanced_table_renderer.py`

**Role:** Takes a `TableStructureSchema` + `pd.DataFrame` + `PresentationTheme` and renders the table directly onto a `python-pptx` slide object.

**Key Responsibilities:**

1. **Header Rendering:**
   - Walk the `header_tree` to compute column spans (`colspan`) for each header group
   - Compute the total number of header rows (max depth of the tree)
   - For each header level, render merged cells spanning the correct columns
   - Apply theme colors to header backgrounds and text
   - Support 1, 2, or 3 header row levels

2. **Data Rendering:**
   - For each leaf `ColumnSpec`, pull data from the DataFrame using `source_column` or compute via `computation`
   - Format values according to `number_format`
   - Apply `conditional_format` using `heatmap_config` to compute per-cell background colors
   - Apply `row_styles` rules for totals and special rows

3. **Heatmap Computation:**
   - For `HEATMAP_DIVERGING`: Map values below center to min_color→mid_color, values above center to mid_color→max_color
   - For `HEATMAP_SEQUENTIAL`: Map values from min to max across the color range
   - Use linear interpolation in RGB space for smooth gradients
   - Compute per-column min/max if not overridden

4. **Cell Merging for Headers:**
   ```
   Example for the "Category Wise Break-Up" table:
   
   Row 0 (super):  [Category (rowspan=2)] [Months (colspan=3)] [Abs Growth (colspan=2)] [Rel Growth (colspan=2)]
   Row 1 (leaf):   [                    ] [Mar-25] [Jul-25] [Aug-25] [Mar-25 to Jul-25] [MoM (Jul to Aug)] [Mar-25 to Jul-25] [MoM (Jul to Aug)]
   
   Example for "Debt Deep Dive – Corporate":
   
   Row 0 (super):  [Debt Schemes (rowspan=2)] [Corporate (colspan=7)]
   Row 1 (leaf):   [                        ] [Mar-25] [Jul-25] [Abs Growth...] [Rel. Growth...] [Aug-25] [Abs Growth...] [Rel. Growth...]
   ```

5. **Theme Integration:**
   - Use `PresentationTheme.primary_color` for header backgrounds (unless overridden in the schema)
   - Use `PresentationTheme.font_body` and `font_heading` for data and header cells
   - Derive alternating row colors from theme's light palette

## 6. AdvancedTableRenderer — Implementation Sketch

### Core Algorithm: Header Tree → Merged Cells

```python
def _compute_header_layout(header_tree: list) -> tuple[list[list[CellInfo]], int]:
    """
    Walk the header tree and produce a grid of header cells with merge info.
    
    Returns:
        - header_grid: list of rows, each row is a list of CellInfo(text, colspan, rowspan, style)
        - max_depth: total number of header rows
    """
    max_depth = _get_max_depth(header_tree)
    grid = [[None] * total_leaf_count for _ in range(max_depth)]
    
    col_offset = 0
    for node in header_tree:
        _place_node(grid, node, row=0, col=col_offset, max_depth=max_depth)
        col_offset += _count_leaves(node)
    
    return grid, max_depth

def _place_node(grid, node, row, col, max_depth):
    if isinstance(node, ColumnSpec):
        # Leaf node — spans remaining rows
        rowspan = max_depth - row
        grid[row][col] = CellInfo(node.display_name, colspan=1, rowspan=rowspan, is_leaf=True)
    elif isinstance(node, HeaderGroup):
        # Group node — spans all child leaves horizontally
        colspan = _count_leaves(node)
        grid[row][col] = CellInfo(node.display_name, colspan=colspan, rowspan=1, is_leaf=False)
        child_col = col
        for child in node.children:
            _place_node(grid, child, row + 1, child_col, max_depth)
            child_col += _count_leaves(child)
```

### Core Algorithm: Heatmap Color Computation

```python
def _compute_heatmap_color(value: float, config: HeatmapConfig, col_min: float, col_max: float) -> str:
    """Returns hex color string for a cell value."""
    if config.type == ConditionalFormatType.HEATMAP_DIVERGING:
        if value <= config.center_value:
            # Interpolate min_color → mid_color
            ratio = (value - col_min) / (config.center_value - col_min) if col_min != config.center_value else 0.5
            return _interpolate_color(config.min_color, config.mid_color, ratio)
        else:
            # Interpolate mid_color → max_color
            ratio = (value - config.center_value) / (col_max - config.center_value) if col_max != config.center_value else 0.5
            return _interpolate_color(config.mid_color, config.max_color, ratio)
```

### python-pptx Rendering

```python
from pptx.util import Inches, Pt, Emu
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN

def render(slide, schema: TableStructureSchema, df: pd.DataFrame, theme: PresentationTheme):
    header_grid, num_header_rows = _compute_header_layout(schema.header_tree)
    num_data_rows = len(df) if schema.max_rows is None else min(len(df), schema.max_rows)
    total_rows = num_header_rows + num_data_rows + 1  # +1 for row label header row is part of header
    total_cols = _count_total_leaves(schema.header_tree) + 1  # +1 for row label column
    
    # Create the pptx table
    table_shape = slide.shapes.add_table(
        rows=total_rows,
        cols=total_cols,
        left=Inches(schema.table_left_inches or 0.5),
        top=Inches(schema.table_top_inches or 1.5),
        width=Inches(schema.table_width_inches or 9.0),
        height=Inches(num_header_rows * 0.4 + num_data_rows * 0.35)
    )
    table = table_shape.table
    
    # 1. Render header rows with merging
    _render_headers(table, header_grid, num_header_rows, schema, theme)
    
    # 2. Render data rows
    leaf_columns = _collect_leaf_columns(schema.header_tree)
    for row_idx, (_, data_row) in enumerate(df.iterrows()):
        pptx_row = num_header_rows + row_idx
        
        # Row label
        _set_cell(table, pptx_row, 0, str(data_row[schema.row_label_column]), schema, theme, is_label=True)
        
        # Data cells
        for col_idx, col_spec in enumerate(leaf_columns):
            value = _get_value(data_row, col_spec)
            formatted = _format_value(value, col_spec.number_format)
            bg_color = _compute_cell_bg(value, col_spec, schema.heatmap_config, df, col_spec.id)
            _set_cell(table, pptx_row, col_idx + 1, formatted, schema, theme, bg_color=bg_color)
        
        # Apply row styles
        _apply_row_styles(table, pptx_row, data_row, schema.row_styles, schema, theme)
```

## 7. Data Flow (Updated)

```
BEFORE (flat tables):
  SlideContentAgent → TableData → TableGenerator → flat table in PPTX

AFTER (multi-level tables):
  SlideContentAgent → analysis_hint + layout_type="advanced_table"
       ↓
  DataTableEngine / DuckDB → raw pd.DataFrame
       ↓
  TableStructureAgent (LLM call) → TableStructureSchema (JSON)
       ↓
  AdvancedTableRenderer → multi-level table with heatmap in PPTX

FALLBACK:
  If TableStructureAgent fails → fall back to existing TableGenerator pipeline
```

## 8. Theme Integration

The `AdvancedTableRenderer` must respect the `PresentationTheme` for:

| Element | Theme Property | Fallback |
|---------|---------------|----------|
| Header background | `primary_color` | `#8B0000` (dark red) |
| Header text | `text_on_primary` or white | `#FFFFFF` |
| Super-header bg | `primary_color` (darker shade) | Darken primary by 20% |
| Data text | `text_color` | `#333333` |
| Alternating rows | `background_light` | `#F9F5F0` |
| Grand total row bg | `primary_color` at 15% opacity | `#F0E0E0` |
| Heatmap positive | `accent_color` or green | `#4CAF50` |
| Heatmap negative | `error_color` or red | `#FF6B6B` |
| Heatmap neutral | `background_light` or yellow | `#FFFFCC` |
| Grid lines | `border_color` or muted | `#D0D0D0` |

## 9. Edge Cases & Fail-Open Strategy

| Scenario | Handling |
|----------|----------|
| TableStructureAgent returns invalid schema | Log error, fall back to `RichTableGenerator` |
| DataFrame has no numeric columns | Produce flat table (no heatmap), log warning |
| Header depth > 3 levels | Cap at 3, flatten deeper levels |
| Too many columns (>12) | Agent should split into multiple tables or select top columns |
| Too many rows (>25) | Agent should set `max_rows` and add "Top N shown" footnote |
| Missing source_column in DataFrame | Skip column, log warning |
| All values in a column are identical | Skip heatmap for that column (no gradient) |
| computation formula errors | Fall back to showing raw source_column |
| DuckDB pipeline fails | Use DataTableEngine (pandas) as existing fallback, then feed to TableStructureAgent |
